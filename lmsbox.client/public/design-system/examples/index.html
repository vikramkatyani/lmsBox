Principle

No local CSS

Components inherit identity from the theme. Override only when content truly requires it.

Use lms-panel for longer prose blocks. Strong text returns to the primary colour so key phrases stand out without breaking the calm reading rhythm.

Spacing between paragraphs is built in. Pair with .lms-bullets when you need a list.

  • Responsive from 320px to 1920px

Click reveal

Hidden content stays closed until the learner chooses to open it.

Use this for key definitions, worked answers, or moments of discovery. The expand animation and plus-to-close rotation come from the theme.

Accordion

Instructional designers can drag components onto a page and trust they will match — without writing CSS.

Set data-exclusive=".lms-accordion__item" so only one panel is open at a time — useful for FAQs and “one question at a time” flows.

Triggers are real buttons with aria-expanded. Focus rings use the accent colour for WCAG-visible focus.
